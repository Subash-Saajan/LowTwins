# LowTwins

Storefront for a clothing brand, built with Next.js, TypeScript and GSAP.

**Live:** https://lowtwins.vercel.app

- Home page with a hero, fashion categories, best sellers, testimonials and a newsletter sign-up
- Product listing and product detail pages (`/products` and `/product/[id]`), driven by typed product data
- Entrance and scroll animations with GSAP

## Run locally

```bash
npm install
npm run dev
```
